# Python Data Studies & Warmups

Repositório dedicado aos meus estudos práticos de Python voltados para Ciência de Dados e Engenharia Analítica, cobrindo exercícios, algoritmos e manipulação de dados realizados em cursos da Alura.

## Estrutura do Repositório

```text
alura/
├── pandas/             # Manipulação e análise de dados tabulares
│   ├── warmups/        # Exercícios práticos e desafios de DataFrames
│   └── pandas.ipynb    # Notebook exploratório de análise de dados
└── python-dados/       # Fundamentos de lógica, estruturas de dados e scripts
    ├── notebook-collab/# Notebooks práticos
    └── warmup_*.py     # Exercícios de dicionários, conjuntos, loops e tratamento de erros
```

## Tópicos Praticados
- **Estruturas de Dados**: Dicionários, listas, tuplas e conjuntos (`sets` com `isdisjoint`, operações de intersecção).
- **Tratamento de Exceções**: Blocos `try/except` defensivos e tratamento de erros.
- **Manipulação de Dados com Pandas**: Filtragem booleana, criação de colunas condicionais, agregações e agrupamentos (`groupby`).
- **Clean Code**: Boas práticas de nomenclatura, funções com responsabilidade única e modularização.
