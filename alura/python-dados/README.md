# Cursos de Python e Dados - Alura

Este diretório contém os exercícios práticos e scripts iniciais (warmups) realizados durante os seguintes cursos da Alura:
- **Python para Dados: primeiros passos**
- **Python para Dados: trabalhando com funções, estruturas de dados e exceções**

Todos os scripts `warmup_*.py` presentes nesta pasta fazem parte do contexto de aprendizado destes dois cursos, cobrindo tópicos como listas, dicionários, tratamento de exceções, funções e estruturas de dados fundamentais na linguagem Python.
