# Curso de Pandas - Alura

Este diretório contém os estudos, anotações no notebook (`pandas.ipynb`) e exercícios (`warmups/`) relacionados ao aprendizado no seguinte curso:
- **Pandas: conhecendo a biblioteca**

Os estudos deste curso foram pausados temporariamente para a aplicação prática dos conhecimentos no projeto de auditoria (ver pasta `projetos/auditoria_agencia`). O objetivo principal desta pasta é concentrar as experimentações com manipulação de DataFrames, filtragens, limpeza de dados (ETL básico) e exploração analítica de datasets usando Pandas.
